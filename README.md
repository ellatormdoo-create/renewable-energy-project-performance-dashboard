# Renewable Energy Project Performance Dashboard

## Project Overview

This project presents an interactive Business Intelligence dashboard developed using Microsoft Power BI to examine renewable energy project performance, energy delivery, community impact, grievance management, and Environmental and Social (E&S) monitoring.

The dashboard demonstrates how data analytics can support project monitoring, operational oversight, and evidence-based decision-making in the renewable energy sector.

**Project type:** Independent portfolio project  
**Tools:** Microsoft Power BI, Microsoft Excel, DAX  
**Data:** Fictional, illustrative dataset developed for demonstration  
**Reporting snapshot:** 30 June 2026

## Project Objectives

- Monitor renewable energy project implementation and milestone progress.
- Track planned renewable energy generation capacity.
- Examine energy delivered and new community connections.
- Monitor grievance resolution and overdue cases.
- Track completed and overdue Environmental and Social actions.
- Demonstrate how interactive dashboards can support management decisions.

## Dashboard Structure

The report contains three pages:

### 1. Project Overview
Provides a summary of project implementation through:
- Total number of projects.
- Total planned capacity (kWp).
- Milestone completion rate.
- Projects by implementation status.

### 2. Community Impact
Examines community-level energy delivery through:
- Total energy delivered (kWh).
- Total new connections.
- Monthly energy delivery trends.

### 3. Grievances & E&S Monitoring
Provides indicators for:
- Open grievances.
- On-time grievance resolution rate.
- Completed E&S actions.

## Data and Methodology

The project uses a fictional dataset structured across four related tables:

- Projects
- Community Impact
- Grievances
- Environmental and Social Monitoring

The tables were imported into Power BI, prepared using Power Query, and connected through a relational data model using project identifiers.

DAX measures were developed to calculate key performance indicators, including project counts, planned capacity, milestone completion, energy delivered, new connections, grievance resolution, and E&S action status.

## Important Data Disclaimer

This is an independent portfolio demonstration. All figures and records are fictional and illustrative. They do not represent actual operational, financial, environmental, or social performance data from any renewable energy company.

The dashboard should therefore be interpreted as a demonstration of analytical and reporting capabilities, not as an assessment of a real organisation.
